# Icons

These SVGs are vendored so the shell does not depend on an icon font.

## Tabler Icons

Source: <https://github.com/tabler/tabler-icons>
License: MIT, stored in `LICENSES/tabler-icons-MIT.txt`.

Downloaded from the official outline SVG set and adjusted to a `1.75` stroke with the shell role colors baked in:

- `bluetooth`
- `bluetooth-off`
- `wifi`
- `wifi-off`
- `network`
- `network-off`
- `moon`
- `moon-off`
- `logout`
- `bell`
- `refresh`
- `power`
- `arrow-down`
- `arrow-up`
- `search`
