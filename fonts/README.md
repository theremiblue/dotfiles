# Fonts

This directory contains third-party font packages used by these dotfiles.
The font files are redistributed unmodified, with their upstream license files
and source notes kept alongside each family.

This repository does not claim ownership of these fonts. Each font remains
under its upstream license.

## License Summary

The included font files are distributed under the SIL Open Font License 3.1.
The full license text for each family is included in that family's directory.

The OFL allows redistribution and bundling, including in public repositories,
provided the license and copyright notices stay with the fonts and the fonts
are not sold by themselves.

Some families define Reserved Font Names. If these fonts are modified, those
reserved names must not be used for the modified versions unless the copyright
holder grants explicit permission.
